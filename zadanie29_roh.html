1. W jaki sposób można określić właściwość danego obiektu. Dwa sposoby wraz z przykładami

Pierwszy sposób to zapis z kropką: nazwaObiektu.właściwość = wartość

Przykład: auto.marka = "Opel"; auto.rok = 1996;

Drugi sposób to zapis z nawiasami kwadratowymi: nazwaObiektu["właściwość"] = wartość

Przykład: auto["cena"] = 25000;

2. W jaki sposób można odwołać się do pól właściwości i metod

Odwołujemy się przez nazwę obiektu oraz kropkę przed nazwą właściwości lub metody.

Przykład: console.log(samochod1.kolor);

Przykład metody: samochod1.pokaz();

3. Wymień cechy charakterystyczne konstruktora

Konstruktor jest uruchamiany automatycznie podczas tworzenia obiektu. Ma taką samą nazwę jak funkcja konstruktora. Nie zwraca wartości. Może przyjmować argumenty. Służy do inicjalizacji pól obiektu i współpracuje z operatorem new.

4. Konstruowanie obiektu na podstawie przykładu. Obiekt ma trzy pola oraz jedną metodę

Przykład obiektu z trzema polami i jedną metodą:

var osoba = {
nazwisko: "Kowalski",
imie: "Jan",
zawod: "piekarz",
wyswietl: function() { document.write(this.nazwisko + " " + this.imie); }
}

5. Znaczenie słowa this. Jak oddzielamy pola oraz metody

Słowo this pozwala odwołać się do bieżącego obiektu z jego wnętrza, czyli do jego pól i metod. Pola i metody w definicji obiektu oddzielamy przecinkami.

6. Konstruktor w JS na podstawie przykładu wraz z opisem

Konstruktor w JavaScript to zwykła funkcja używana do tworzenia obiektów. Przypisuje wartości do pól przy użyciu słowa this.

function Klient(nazwisko, imie, zawod) {
this.nazwisko = nazwisko;
this.imie = imie;
this.zawod = zawod;
this.wypisz = function() { alert(this.nazwisko + " " + this.imie); }
}

Podczas tworzenia obiektu wartości parametrów trafiają do pól nowego obiektu.

7. Znaczenie słowa kluczowego new wraz z przykładem

Słowo new tworzy nowy obiekt na podstawie funkcji konstruktora.

Przykład:

var osoba1 = new Klient("Kowalski","Jan","kierowca");
var osoba2 = new Klient("Nowak","Anna","sekretarka");

Powstają dwa niezależne obiekty z tymi samymi polami i metodami.

8. Znaczenie słowa kluczowego prototype wraz z przykładem i opisem

Prototype służy do dodawania metod i właściwości do wszystkich obiektów tworzonych przez dany konstruktor.

Przykład:

function Klient() {
this.nazwisko = "Bielski";
this.imie = "Paweł";
}
Klient.prototype.pisz = function() { document.write(this.nazwisko + " " + this.imie); };
Klient.prototype.zawod = "kierowca";
var o1 = new Klient();
o1.pisz();

Metody i pola dodane przez prototype są dostępne dla każdego nowego obiektu utworzonego z tego konstruktora oraz mogą być dodawane także do już istniejących obiektów.
